# 滚动条贴右布局调整设计

## 目标
- 内容保持居中与当前宽度观感
- 滚动条贴窗口最右侧
- 不引入新的全屏拉伸感

## 方案（已选）
**外层滚动，内层居中**
- 让外层主容器负责垂直滚动，滚动条天然贴右
- 内容容器继续保留居中宽度与最大宽度
- 避免在内容容器上做 overflow 裁剪

## 影响范围
- `src/renderer/index.css`：外层布局滚动容器
- `src/renderer/components/nexus/NexusDashboard.css`：内容容器居中规则

## 验收标准
- 滚动条在窗口最右侧
- 内容依然居中，不出现左右空白“白边块”
