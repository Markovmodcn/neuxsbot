## 如何使用

### 智能对话

配置完成后，返回主界面，你可以：

- 在输入框中描述你的任务，比如「帮我分析这份 Excel 数据」
- 根据需要在左侧边栏的「技能」中启用相关功能
- 点击发送按钮，开始与 AI 协作

**支持的功能：**
- 上下文理解 — 记住对话历史，理解前后文关系
- 文件上传 — 拖拽文件到对话框，直接让 AI 分析处理
- 代码高亮 — 自动识别代码块并提供语法高亮
- 多轮迭代 — 可以对 AI 的输出提出修改意见，逐步完善结果

### 任务管理

左侧边栏是你的任务历史中心，所有对话会自动保存：

- **新建任务** — 点击「新建任务」开始一个全新的对话
- **搜索任务** — 通过关键词快速找到历史任务
- **任务操作** — 点击任务旁的 ... 菜单，可以重命名、置顶或删除任务

### 技能系统

技能是 NexusBot 的核心特性，每个技能都是一个专业能力模块：

- 点击左侧边栏的「技能」按钮
- 浏览可用技能列表
- 点击技能旁的开关启用/禁用技能

**工作原理：**
- 启用技能后，AI 会自动获得该领域的专业知识和工具
- 多个技能可以同时启用，AI 会根据任务自动选择使用技能
- 可以在对话过程中随时添加或移除技能

### 自定义技能

NexusBot 允许你创建自己的技能，让 AI 掌握你的特定工作流程：

1. 启用 `skill-creator` 技能
2. 描述你想要的能力
3. 技能创建器会引导你完善细节
4. 创建完成后，新技能会出现在技能列表中

👉 [查看自定义技能开发文档](https://www.neuxsbot.com/docs#自定义技能)
