## 什么是 NexusBot？

NexusBot 是基于全球热门开源项目 **OpenClaw** 深度定制的中国版 AI 工作流助手。

它不仅仅是一个 AI 对话工具，而是一个能真正**执行任务**的数字员工——从被动回答升级为主动执行，让 AI 像人类一样理解、规划并操作你的设备。

## 常见问题

**Q: 真的完全免费吗？**

是的，所有核心功能永久免费，无隐藏费用。

**Q: 数据安全吗？**

所有数据存储在本地，完全由你掌控。支持本地模型离线使用，数据不出本地。

**Q: 支持哪些 AI 模型？**

支持 OpenAI、Claude、Gemini、DeepSeek、通义千问、智谱 AI、月之暗面等国内外主流模型，以及 Ollama 本地部署。

**Q: 如何在手机上控制？**

配置钉钉/飞书/企业微信机器人后，即可在手机端远程操控 PC 端的 NexusBot。
